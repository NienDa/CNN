# CNN Flower Classification

## Dataset

Project sử dụng dataset ảnh hoa gồm 10 lớp để huấn luyện mô hình CNN.

### Các lớp dữ liệu

- Daisy
- Dandelion
- Hibiscus
- Lotus
- Orchid
- Rose
- Sunflower
- Tulip
- Lavender
- Lily

### dataset
link: https://www.kaggle.com/datasets/utkarshsaxenadn/flower-classification-5-classes-roselilyetc
